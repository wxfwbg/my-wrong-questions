# 我的错题本 - 安装与使用指南

## 🚀 快速开始（5分钟搞定）

### 方法一：直接打开（最简单）

1. 在电脑上找到文件夹 `F:\I.AI\workplace\my-wrong-questions-app`
2. 双击 `index.html` 文件
3. 在浏览器中打开后，用手机扫描显示的二维码（如果有）
4. 或者把文件夹复制到手机存储中，用手机浏览器打开 `index.html`

### 方法二：本地服务器（推荐用于测试）

1. 打开 `启动预览.bat` 文件
2. 浏览器访问 http://localhost:8080
3. 手机和电脑连接同一个WiFi，手机访问显示的IP地址

## 📱 手机端安装（像原生APP一样）

### iPhone / iPad
1. 用Safari打开APP
2. 点击底部 **分享按钮** (方形箭头↑)
3. 向下滚动，点击 **"添加到主屏幕"**
4. 点击右上角 **"添加"**
5. 桌面上会出现APP图标，可以像普通APP一样打开

### Android
1. 用Chrome打开APP
2. 点击右上角 **菜单** (三个点)
3. 选择 **"安装应用"** 或 **"添加到主屏幕"**
4. 确认安装后，桌面上会出现APP图标

## ✨ 功能使用说明

### 1️⃣ 注册登录
- 首次使用需要注册账号
- 输入用户名和密码（至少6位）
- 注册后自动登录

### 2️⃣ 上传试卷
1. 点击 **上传试卷** 或底部相机图标
2. 选择科目（语文/数学/英语/物理/化学/生物）
3. 点击拍照区域，拍摄试卷照片
4. 点击 **开始批改**
5. 选择每道题的答案
6. 提交后自动计算分数，错题自动加入错题库

### 3️⃣ 查看错题库
- 显示所有收集的错题
- 可以按科目筛选
- 显示每道题的练习次数

### 4️⃣ 开始刷题
- 从错题库随机抽取10道题
- 选择答案后立即显示对错
- 完成后返回首页

### 5️⃣ 手动添加错题
- 点击 **添加错题**
- 选择科目
- 可拍照上传题目图片
- 输入题目内容和正确答案
- 保存到错题库

## ⚠️ 注意事项

1. **数据存储**: 所有数据保存在手机浏览器本地，换手机或清缓存会丢失
2. **照片权限**: 首次拍照会请求相机权限，请允许
3. **离线使用**: 安装到桌面后，可以在无网络时使用（部分功能）
4. **浏览器推荐**: 
   - iPhone推荐用Safari
   - Android推荐用Chrome

## 🔧 技术说明

- 使用HTML5 + CSS3 + JavaScript开发
- 使用IndexedDB存储数据
- 支持PWA（可添加到桌面）
- 响应式设计，适配各种手机屏幕
- 无需后端服务器，纯前端应用

## 📞 遇到问题？

如果APP无法正常使用：
1. 确认手机已连接网络
2. 尝试刷新页面
3. 清除浏览器缓存后重新打开
4. 重新安装到桌面
